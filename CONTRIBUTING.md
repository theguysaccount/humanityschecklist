# Contributing

Humanity's Checklist is open source and gets better when more people sharpen it. You can:

- **Open an issue** with an idea, a question the site should answer, or something that's wrong.
- **Open a pull request** to add questions (`questions.json`) or improve a deep dive (`ITEMS` in `humanitys-checklist.html`).
- **Point your AI agent at this repository.** [AGENTS.md](AGENTS.md) has step-by-step instructions it can follow, including the writing rules and how to check a change.

Keep pull requests focused, cite a source for any fact or number, and run `python3 build.py` before you open one. Contributions are published under the project's licenses (see the README).
